# 2027 겨울 물꼬방 — 다정한 바다 산책 코스 메이커

## 기존 GitHub → Streamlit 배포 방법
1. 이 ZIP을 내려받아 **한 번만** 압축을 풉니다.
2. 안쪽의 파일 **전체(폴더가 아니라 파일)**를 선택하여 `https://github.com/Geullang/dajeong-sea` 저장소의 **최상위 디렉터리**에 업로드합니다. 기존 파일이 있으면 같은 이름으로 교체합니다.
3. GitHub에서 `Commit changes`를 누릅니다.
4. 기존 Streamlit 앱 `https://dajeong-sea-jnbtnkxhn5vhxwskczvu7p.streamlit.app/`이 재배포된 뒤 새로고침합니다. 메인 파일은 `app.py`입니다.
5. 기존 Streamlit Secrets의 `KAKAO_REST_API_KEY`는 그대로 유지합니다. **절대로 GitHub에 Secrets의 실제 키를 올리지 않습니다.**

## 화면 구조
- 첫 화면: 출발지, 도착지, 7개 지역, 관심 분야 6개, 시간, 인원, 이동수단 입력
- 둘째 화면: 카카오에서 실제로 확인된 장소만 지역별 최대 3개/분야씩 카드로 표시. 장소 정보 링크, 선택/해제
- 셋째 화면: 앱이 장소를 선택해 방문 순서를 재배치하고 시작 시각·예상 체류 시간·총시간·코스 지도를 표시
- 넷째 화면: 전체 지도, 요약, JSON 다운로드, 일정 텍스트 공유

**화면 4개가 한 화면에 길게 나열되지 않습니다. 다음/이전 버튼으로 차례대로 이동합니다.**

## 사진 이용 조건
Google Places의 **실제 장소 사진**을 사용하려면 별도의 Google Cloud API 키를 발급받아 Streamlit Secrets에 `GOOGLE_PLACES_API_KEY`로 설정해야 합니다. Google Places API (New)를 활성화하고 결제 계정 및 월 사용량 상한을 검토해야 합니다. **이 키도 GitHub에 올리지 않습니다.**
- 사진을 조회할 때 가게 이름 및 약 280m 이내 위치가 일치하는 장소만 받아옵니다.
- 사진이 없거나 요청에 실패하면 `확인된 사진 없음`으로 표시합니다. 다른 가게 사진이나 생성 삽화로 바꿔치기하지 않습니다.
- 제공되는 사진은 Google Places 서비스의 사용 조건, 저작자 출처표시 요구, 지도 연계 정책을 따릅니다. 행사 공개 전에 Google 약관 및 지도와의 병용을 검토하십시오.

## 길찾기 안내
- 도보: Kakao walking routing을 시도합니다. 실제 응답이 없으면 구간별 직선거리 보정 **추정**만 적용하며 지도에는 주황색 점선으로 표시됩니다. 실경로로 표시하지 않습니다.
- 택시/자동차: 현재 실시간 차량 경로 API가 구현되어 있지 않아 거리·시간은 **추정치**입니다. 배포 및 실제 행사 전 보완해야 합니다.
- 영업시간·휴무일·가격·예약 여부는 API로 실시간 검증하지 않으므로 사용자는 장소 정보 링크를 확인해야 합니다.
- 7개 코스별로 20개 이상 장소 **후보 데이터**가 포함돼 있지만 모두 운영 검증을 마쳤다는 뜻이 아닙니다. 검색 시 카카오에서 확인한 장소만 추천됩니다.
