# 부산 산책 코스 메이커 — 사용자 장소 목록 통합본

## 포함
- 제공된 네이버 저장 목록에서 80개 이상의 장소를 수동 정리한 1차 데이터 (`places.json`)
- 7개 코스 중 하나 선택 시 해당 코스 장소만 화면 2에 표시
- 관심 분야 필터, 실제 주소 표시, 네이버 지도 검색 링크

## 제한
- 사용자 제공 전체 목록의 모든 항목을 수록한 것은 아닙니다. 추가 장소 데이터는 다음 통합에서 보완해야 합니다.
- 지도 좌표, 실제 사진, 영업시간은 아직 검증되지 않아 임의로 생성하지 않았습니다.
- 실제 이동 시간 최적화 및 저장 공유는 아직 미연동입니다.
- 카카오 REST API 키와 지오코딩을 연결해야 좌표가 확보됩니다.

## 실행
`pip install -r requirements.txt` 다음 `streamlit run app.py`
