# 부산 산책 코스 메이커 — 1단계 디자인 확인용

이 ZIP은 **최종 앱이 아닙니다**. 첨부된 4개 모바일 화면을 참고하여 화면 배치와 단계 이동, 다중 선택 상태를 검토하는 개발 빌드입니다.

## 실행
1. ZIP 압축을 풀고 폴더 안 `app.py`, `mobile.html`, `requirements.txt`를 GitHub 저장소 최상위에 업로드합니다.
2. Streamlit Community Cloud에서 `app.py`를 메인 파일로 선택하여 배포합니다.
3. 별도의 API 키는 아직 필요하지 않습니다.

## 구현 범위
- 4개 화면 전환, 7개 탐방 코스 복수 선택, 6개 관심 분야 복수 선택
- 출발지/도착지 텍스트 입력, 시간/인원/이동수단 선택
- 장소 카드 선택, 선택된 장소 목록을 코스 화면에 표시
- 모바일용 CSS 레이아웃

## 미구현 및 유의 사항
- 사진은 시각 배치용 외부 스톡 이미지이며 부산 실제 장소 사진이 아닙니다. 이 빌드를 실제 장소 추천용으로 사용하지 마세요.
- 장소 카드는 UI 예시입니다. 장소의 실제 존재·주소·영업시간을 검증한 데이터가 아닙니다.
- 지도 영역은 플레이스홀더이며 실제 경로·핀·소요 시간은 표시하지 않습니다.
- 방문 순서 최적화, 위치 검색 API, 공유 링크, 영구 저장은 미구현입니다.
- 사용자 입력은 HTML iframe 내부 메모리에 유지되며 브라우저 새로고침 시 초기화됩니다.
- 모바일 실제 기기 스크린샷 비교 테스트는 아직 수행하지 않았습니다.
